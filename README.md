# Loyalty & Rewards for WooCommerce: releases

Installable releases of the Loyalty & Rewards for WooCommerce plugin. The source code is kept in a separate repository.

Stores running the plugin update themselves from here. To install it on a new store, download the latest `wc-loyalty-engine-x.y.z.zip` from [Releases](../../releases/latest) and upload it in WordPress under **Plugins → Add New → Upload Plugin**.

`info.json` describes the latest version and is what installed stores check. It is updated automatically with each release; don't edit it by hand.
